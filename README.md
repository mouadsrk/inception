# 🐳 Inception

**Inception** is a containerized infrastructure project developed as part of the 42 Network curriculum. It simulates a real-world web hosting environment by deploying multiple services with **Docker Compose**, including **Nginx**, **WordPress**, and **MariaDB**.

---

## 🎯 Project Objectives

- Build a multi-service Docker Compose setup with isolated containers
- Configure Nginx as a reverse proxy for the WordPress service
- Deploy a fully functional WordPress site backed by a MariaDB database
- Manage data persistence with Docker volumes
- Handle networking between containers for seamless communication
- Implement service health checks and automatic restart policies

---

## 🛠️ Technologies

- Docker  
- Docker Compose  
- Nginx  
- WordPress  
- MariaDB (MySQL)
